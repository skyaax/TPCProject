# TPCProject

Small Python project for practicing matrix operations and basic image transformations with NumPy and Pillow.

## What is included

- Matrix addition, subtraction, multiplication, transpose, and scalar multiplication
- Image-to-matrix and matrix-to-image conversion helpers
- Image rotation, scaling, skewing, grayscale conversion, and edge detection
- `2.bmp` as the sample input image used by `Main.py`

## Requirements

- Python 3
- NumPy
- Pillow

Install the dependencies:

```bash
pip install numpy pillow
```

## Run

```bash
python Main.py
```

Most demo calls in `Main.py` are commented out. Uncomment the transformation you want to test, then run the script again.

Generated image outputs and local development files are ignored by Git so the repository stays focused on the source code and input assets.
